## Database name can be find
```
/var/www/html/<project_folder>/protected/config/databse.php
```
Show All Running Process for all Database

```
SHOW FULL PROCESSLIST;
```

## Show All Running Process for Specific Database

```
SELECT *
FROM information_schema.PROCESSLIST
WHERE DB = 'your_database_name';
```

## When Server Slow reason by data base issue

```
systemctl apache2 reload
```
