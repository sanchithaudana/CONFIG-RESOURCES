
## Check permissions
```sql
SHOW GRANTS FOR '<USER>'@'localhost';
```

## Give write access
```sql
GRANT INSERT, UPDATE, DELETE ON *.* TO '<USER>'@'%';
```

## Give read access
```sql
GRANT SELECT ON <DB>.* TO '<USER>'@'%';
```

## Give all permissions for a particular database
```sql
GRANT ALL PRIVILEGES ON <DB>.* TO '<USER>'@'%';
```

## Give Read permission for all databases
```sql
GRANT SELECT ON *.* TO 'readonly_user'@'%';
```

## Give Read/Write permissions for all databases
```sql
GRANT ALL ON *.* TO 'readonly_user'@'%';
```

## Give access to view procedures
```sql
GRANT SHOW_ROUTINE ON *.* TO '<USER>'@'%';
```

## Lock User
```sql
ALTER USER '<USER>'@'%' ACCOUNT LOCK;
```

## Unlock User
```sql
ALTER USER '<USER>'@'%' ACCOUNT UNLOCK;
```

## Revoke Access
```sql
REVOKE SELECT ON <DB>.* FROM '<USER>'@'%';
```
