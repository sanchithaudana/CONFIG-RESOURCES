
## <span style="color: var(--color-cyan)">Useful tmux commands</span>

| Action           | Command                       |
| ---------------- | ----------------------------- |
| Create session   | `tmux new -s <name>`          |
| List sessions    | `tmux ls`                     |
| Reattach session | `tmux attach -t <name>`       |
| Detach session   | `Ctrl + B`, then `D`          |
| Kill session     | `tmux kill-session -t <name>` |


## <span style="color: var(--color-green)">Get Database Dump</span>

### <span style="color: var(--color-green)">Encrypted</span>
```bash
BACKUPDIR="/var/log/backup/mariadb/manual_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$BACKUPDIR" && chmod 700 "$BACKUPDIR"

mysqldump \
  --user=YOUR_MYSQL_USER \
  --password \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --hex-blob \
  --set-gtid-purged=OFF \
  --extended-insert=TRUE \
  --databases DB_NAME \
  | gzip -9 \
  | gpg --symmetric \
      --cipher-algo AES256 \
      --output "$BACKUPDIR/DB_NAME_$(date +%Y%m%d_%H%M%S).sql.gz.gpg"
```

### <span style="color: var(--color-green)">Plain-Text</span>
```bash
mysqldump \
  --user=YOUR_MYSQL_USER \
  --password \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --hex-blob \
  --set-gtid-purged=OFF \
  --databases <DB_NAME> \
  | gzip -9 > <DB_NAME>_$(date +%Y%m%d_%H%M%S).sql.gz
```

## <span style="color: var(--color-orange)">Restore Database Dump</span>

### <span style="color: var(--color-yellow)">Verify the Backup Before Restoring</span>
```bash
gzip -t <DB_NAME>_20260721_143000.sql.gz && echo "Backup file is valid"
```

### <span style="color: var(--color-orange)">Restore Dump (Encrypted)</span>

#### Compressed
```bash
gpg --batch --yes --passphrase 'GPG_PASSWORD' --decrypt <DUMP_NAME>.sql.gz.gpg | gunzip | mysql -u root -p'MYSQL_ROOT_PASSWORD' <DB_NAME>
```

### <span style="color: var(--color-orange)">Restore Dump (Plain-Text)</span>

#### Compressed
```bash
gunzip -c <DUMP_NAME>.sql.gz | mysql -u root -p'MYSQL_ROOT_PASSWORD' <DB_NAME>
```

#### Un-Compressed
```bash
mysql -u root -p'MYSQL_ROOT_PASSWORD' <DB_NAME> < <DUMP_NAME>.sql
```



## <span style="color: var(--color-green)">Compress and Encrypt an Existing SQL Dump</span>

Run these commands from the directory containing the `.sql` dump. Compress first, then encrypt. To reverse the process, decrypt first, then decompress using the steps below.

### <span style="color: var(--color-green)">1. Compress the SQL Dump</span>

```bash
gzip -9 -k -- mint_sejaya_202611192330.sql
```

This creates `mint_sejaya_202611192330.sql.gz`. The `-k` option keeps the original `.sql` file.

### <span style="color: var(--color-green)">2. Encrypt the Compressed Dump</span>

```bash
gpg --symmetric --cipher-algo AES256 \
  --output mint_sejaya_202611192330.sql.gz.gpg \
  mint_sejaya_202611192330.sql.gz
```

Enter the passphrase when GPG prompts you. Only the `.gpg` file is encrypted; the `.sql` and `.sql.gz` files remain unencrypted.

## <span style="color: var(--color-purple)">Decrypt the Database Backup</span>

```bash
gpg --output mint_sejaya_202611192330.sql.gz --decrypt mint_sejaya_202611192330.sql.gz.gpg
```

## <span style="color: var(--color-purple)">Decompress the Backup</span>

```bash
gunzip mint_sejaya_202611192330.sql.gz
```

## <span style="color: var(--color-orange)">Restore the DB</span>

```bash
mysql -u root -p mint_sejaya_20261119 < mint_sejaya_202611192330.sql
```
