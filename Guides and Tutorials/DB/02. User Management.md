
## Creating a secure password
```bash
LC_ALL=C tr -dc 'A-Za-z0-9!@#$%^&*()_+-=' </dev/urandom | head -c 24; echo
```

## Check available users
```sql
SELECT User, Host FROM mysql.user;
```

## Check available permissions for a user
```bash
SHOW GRANTS FOR 'username'@'host';
```

## New user
```bash
CREATE USER 'myapp_user'@'%'IDENTIFIED BY 'StrongRandomPassword!';
```

## Grand Permission to a database
```bash
GRANT ALL PRIVILEGES ON myapp_db.* TO 'myapp_user'@'localhost';

FLUSH PRIVILEGES;
```

## Grant Permission access Get Object

```
GRANT SHOW DATABASES ON *.* TO 'db_user'@'%';
```
```
GRANT SHOW_ROUTINE ON *.* TO 'db_user'@'%';
```

## Reset Password of a user
```sql
ALTER USER 'username'@'localhost' IDENTIFIED BY 'NewStrongPassword!';

FLUSH PRIVILEGES;
```
