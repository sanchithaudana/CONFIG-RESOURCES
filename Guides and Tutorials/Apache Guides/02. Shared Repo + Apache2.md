
## Permission Setup
```bash
REPO=/var/www/html/your-repository
OWNER=minthrm
GROUP=developers
WEBUSER=www-data
```

```bash
# 1. Set repository owner and group
sudo chown -R "$OWNER:$GROUP" "$REPO"

# 2. Directories:
#    - owner rwx
#    - developers rwx
#    - setgid so new objects inherit the developers group
#    - others r-x
sudo find "$REPO" -type d -exec chmod 2775 {} +

# 3. Existing files:
#    Give the developers group read/write access.
#    Existing executable bits are preserved.
sudo find "$REPO" -type f -exec chmod g+rw {} +

# 4. Give developers access to all existing content
sudo setfacl -R -m "g:$GROUP:rwx,m:rwx" "$REPO"

# 5. Give Apache/PHP access to all existing directories
sudo find "$REPO" -type d -exec setfacl -m "u:$WEBUSER:rwx,m:rwx" {} +

# 6. Give Apache/PHP read/write access to all existing files
#    Do NOT give ordinary files executable permission.
sudo find "$REPO" -type f -exec setfacl -m "u:$WEBUSER:rw-,m:rwx" {} +

# 7. Set default ACLs on every existing directory.
#    New content inherits access for both developers and www-data.
sudo find "$REPO" -type d -exec setfacl -m \
"d:u::rwx,d:u:$WEBUSER:rwx,d:g::rwx,d:g:$GROUP:rwx,d:m::rwx,d:o::rx" {} +

# 8. Trust the repository system-wide
sudo git config --system --add safe.directory "$REPO"

# 9. Configure Git as a shared group repository
sudo git -C "$REPO" config core.sharedRepository group
```

## Verification

```bash
ls -ld "$REPO"
ls -ld "$REPO/.git"

getfacl "$REPO"
getfacl "$REPO/.git"

git -C "$REPO" config --get core.sharedRepository
sudo git config --system --get-all safe.directory
```

drwxrwsr-x+ ... minthrm developers ... /var/www/html/your-repository
