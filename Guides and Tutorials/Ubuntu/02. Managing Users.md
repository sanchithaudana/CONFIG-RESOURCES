## Check available users
```bash
cat /etc/passwd
```

## Check available users in a group
```bash
getent group group_name
```

## Creating a user
```bash
adduser <USER_NAME>
```

## Deleting a user
```bash
deluser --remove-home <USER_NAME>
```

## Changing a password
```bash
passwd <USER_NAME>
```

## Giving 'sudo' permissions
```bash
usermod -aG sudo <USER_NAME>
```

## Check user has WRITE access
```bash
sudo -u <USER> test -w <PATH> && echo "Write OK" || echo "No write access"
```

## Remove password access for a user
```bash
sudo passwd -l <USER>
```
