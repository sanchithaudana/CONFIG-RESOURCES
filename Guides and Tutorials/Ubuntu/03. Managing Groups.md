
## show all users in a group

```
getent group <group_name>
```

## Create Group
```bash
sudo groupadd <developers>
```

## Change Group of a directory
```bash
sudo chgrp <GROUP> -R <Path>
```

## Add user to a group
```bash
sudo usermod -aG <GROUP> <USER>
```

## Remove user from a group
```bash
sudo gpasswd -d <USER> <GROUP>
```
